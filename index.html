About this project

Personal Finance Tracker is a small software project for experimenting with conversational expense tracking, data organization, and automation. It is not a bank, financial institution, payment service, or investment advisory service.

Privacy

The project is currently intended for personal testing. Data is processed only for the purpose of providing the expense-tracking functionality. This page does not collect payments or sell personal financial information.
